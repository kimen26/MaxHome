Les voyages du foyer

Un titre, un lieu, deux dates : le voyage apparaît sur le calendrier de l'Agenda et sur la carte d'accueil. Le détail (hébergement, train, programme) reste dans la note, ou dans MaxVoyage.

Le magasin dans l'ordre où on le traverse

La liste de courses suit cet ordre, pas l'alphabet : on entre, on prend le premier groupe, on repart avec le dernier. Un article ajouté tombe dans son groupe, où qu'on soit dans le magasin.

Le chiffre à droite est le nombre d'articles en attente dans ce groupe. Un groupe vide ne s'affiche pas dans la liste.
